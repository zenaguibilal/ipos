# **App Name**: iPOS - Intelligent Point of Sale

## Core Features:

- Sales Interface: User-friendly interface for adding products to the cart, calculating totals, applying discounts, and selecting payment methods (cash, card, e-wallet).
- Product Management: Add, modify, and delete products with images, prices, and inventory quantities.
- Customer Management: Record customer data (name, phone, email), manage loyalty cards, and link sales to the customer's record.
- Supplier Management: Manage supplier data, track invoices, and link products to the appropriate supplier.
- Sales Summary Dashboard: Control panel showing sales summary, customer count, supplier count, and inventory status.
- AI-Powered Stock Alerts: Use a tool to predict when stocks for certain products are likely to run out soon. Use AI to send alerts when restocking is needed based on sales velocity.
- Database: Uses either MongoDB or PostgreSQL.

## Style Guidelines:

- Primary color: Light grayish blue (#A7BBC7) to evoke professionalism, clarity, and dependability. Note: shades of gray requested by user.
- Background color: Very light gray (#F2F4F6) for a clean and modern look, blending well with the primary color.
- Accent color: Pale greenish blue (#D0E8E2) to highlight important elements, providing a subtle contrast.
- Body and headline font: 'Inter' (sans-serif) for a modern, objective, and neutral feel.
- Use clean, simple icons for easy navigation and quick identification of features.
- Responsive design adapting to different screen sizes (mobile, tablet, desktop) with a consistent grid system.
- Subtle animations and transitions to enhance user experience without being distracting.
