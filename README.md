# iPOS - Intelligent Point of Sale (Absolute Edition)

**iPOS** هو تطبيق نقطة بيع (POS) سحابي يعتمد على معمارية **الهيمنة المطلقة للسحابة**.

## ✨ المبادئ التوجيهية

*   **Cloud-Only:** لا يوجد تخزين محلي، لا توجد مزامنة خلفية. البيانات حية أو غير موجودة.
*   **Hard API Wall:** فصل تام بين العميل وقاعدة البيانات.
*   **State Singularity:** إدارة حالة مركزية غير مستمرة (Non-persistent).
*   **Deterministic Logic:** العمليات الحسابية والمالية تتم في طبقة المستودعات على الخادم.

---
**النظام الآن يعمل بمعمارية Purified Cloud-Only لضمان أعلى مستويات الموثوقية.**
