# iPOS - Intelligent Point of Sale

**iPOS** هو تطبيق نقطة بيع (POS) سحابي متطور مصمم لتجارة التجزئة. يعتمد النظام على معمارية **Supabase المطلقة** لضمان دقة البيانات واتساقها في الوقت الفعلي.

## ✨ الميزات الأساسية

*   **إدارة المبيعات:** واجهة كاشير سريعة واحترافية.
*   **إدارة المنتجات:** تتبع المخزون، تنبيهات النقص، واستيراد CSV.
*   **إدارة العملاء:** تتبع الديون، حدود الائتمان، وسجل المشتريات.
*   **إدارة الموردين:** تسجيل المشتريات وتدقيق حسابات الموردين.
*   **المالية والتقارير:** تتبع المصاريف وحسابات الزكاة التجارية.
*   **معمارية حتمية:** جدار حماية API كامل يفصل بين البيانات والواجهة.
*   **أمان عالي:** نظام أدوار (Admin, Manager, Cashier) لحماية العمليات الحساسة.

---
**النظام الآن يعمل بمعمارية Cloud-Only لضمان أعلى مستويات الموثوقية.**
