
# iPOS - Intelligent Point of Sale (Absolute Edition)

**iPOS** est une application de point de vente (POS) cloud basée sur une architecture de **domination absolue du Cloud**.

## ✨ Principes Directeurs

*   **Cloud-Only :** Pas de stockage local, pas de synchronisation en arrière-plan. Les données sont en direct ou n'existent pas.
*   **Hard API Wall :** Séparation totale entre le client et la base de données.
*   **State Singularity :** Gestion d'état centralisée et non persistante.
*   **Deterministic Logic :** Les opérations de calcul et financières sont traitées dans la couche des référentiels sur le serveur.

---
**Le système fonctionne désormais avec une architecture Purified Cloud-Only pour garantir les plus hauts niveaux de fiabilité.**
