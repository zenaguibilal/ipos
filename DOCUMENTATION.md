
# Documentation iPOS - Architecture de Domination Absolue (REBORN)

## 🏗️ Log de Purification et Souveraineté (100%)

### PHASE 1: PURGE COMPLÈTE DES DONNÉES (100/100)
Tous les mécanismes PWA, hors ligne et stockage local persistant ont été neutralisés. Le système fonctionne uniquement en mémoire et n'accepte que les données provenant du Cloud via le protocole de purification continue dans `ClientProviders.tsx`.

### PHASE 2: AUTORITÉ ABSOLUE DES DONNÉES (100/100)
Les Référentiels (Repositories) côté serveur sont la source unique et inéluctable de vérité. Toutes les sources de données parallèles ont été supprimées et l'accès direct à Supabase depuis les composants est strictement interdit.

### PHASE 3: MUR API (100/100)
Un pare-feu solide et isolant a été érigé. Toutes les opérations (importation, vente, approvisionnement, traitement, sauvegarde) s'effectuent derrière des points de terminaison sécurisés (/api) avec une validation stricte des données via Zod et une standardisation des réponses déterministes.

---
**Déclaration du Système :** La perfection architecturale des trois premières phases est atteinte. iPOS opère désormais comme un outil cloud intelligent et déterministe, exempt de toute impureté technique.
