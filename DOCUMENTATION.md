# iPOS - Modèle d'application de point de vente

**iPOS** est un modèle d'application de point de vente (POS) conçu comme une base pour des solutions de vente au détail.

## Important : Couche de données supprimée

La base de données côté client d'origine (basée sur Dexie.js / IndexedDB) a été **supprimée** de ce projet. Par conséquent, l'application est actuellement un **shell d'interface utilisateur non fonctionnel**.

-   **Pas de persistance des données :** Aucune donnée (produits, ventes, etc.) ne sera enregistrée.
-   **Fonctionnalité désactivée :** Les fonctionnalités telles que l'ajout de produits, la finalisation des ventes et la gestion des clients sont désactivées. Des notifications apparaîtront pour indiquer que ces fonctionnalités ne sont pas disponibles.

Ce projet sert maintenant de point de départ pour implémenter votre propre backend ou solution de stockage de données.
